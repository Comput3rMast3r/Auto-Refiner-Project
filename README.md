# Auto-Refiner-Project

### План

I. Реализация auto-ontology refiner
1. Реализовать модуль предобработки документов (парсинг, удаление мусора, чанкинг)
2. Написать модуль LLM-extractor - извлечение сущностей, классов и связей с помощью LLM
3. Представить узлы графа с помощью эмбедера и сделать дедубликацию после LLM-обработки (добавить кластеризатор)
4. Написать модуль - консолидатор онтологии
5. Реализовать модуль-оценщика (refiner) для измерения качества построенной онтологии и сравнение с предыдущими версиями для принятия/отклонения новой версии онтологии
6. Зациклить пункты 2-5, добавить четкий и качественный критерий остановки

II. Валидация решения
1. Подбор knowledge-graph reasoning алгоритма
2. Подбор датасета для оценки этого алгоритма
3. Прогон датасета на выбранном алгоритме
4. Замена модуля формирования knowledge-graph нашим модулем auto-ontology refiner
5. Прогон того же датасета на подмененном алгоритме
6. Снимаем время, ресурсы и качество на обоих прогонах, получаем отличные метрики по сравнению с базовой реализацией и радуемся жизни

Минимальный итог: Полноценный пайплайн итеративного построения knowledge graph из корпусов текстов с изменением состава и структуры графа от итерации к итерации и готовой валидацией этого решения
